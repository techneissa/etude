# Brand marks

Two marks the About page shows beside the links to the project's GitHub page and its Buy Me a
Coffee page. They are the brands' own artwork, kept as the brands publish them, and are not part of
Etude's GPL-3.0 licence: each stays under its owner's terms of use for the mark.

| File | What it is | Source |
| --- | --- | --- |
| `github-mark.svg` | The GitHub mark (Octicons `mark-github`, 24x24 outline). Drawn in one colour, the text colour of the page. | https://github.com/logos |
| `bmc-logo-yellow.png` | The Buy Me a Coffee cup on its yellow tile, 88x88 (the 2x file of the brand's yellow logo). Drawn as it is, with its corners rounded. | https://buymeacoffee.com/brand |
