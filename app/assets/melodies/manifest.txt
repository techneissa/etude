# The Melodies of the Learn screen: the files bundled with the app, and the paths through them.
# One line per record, fields separated by " | ". Blank lines and lines starting with # are ignored.
#
#   file | NAME.mid | title | composer | step | source | licence
#       step: the grade, 1 (right hand, a few keys) to 5 (both hands, wide range)
#       source: where the notes come from; licence: what lets us bundle the file. Both are required.
#   path | id | title | icon
#       icon: sprout, handshake or award
#   goal | path id | NAME.mid | one-line goal
#       the pieces of a path in the order they are played; a goal line is one piece's place in it
#
#   version | NAME.mid | tag
#       a small tag the piece's tile wears beside its title ("Easy", "Original", at most 12 characters):
#       which version a file is, for a piece listed twice under one title. Only those files have one.
#
# A simplified arrangement of a piece is a file of its own: its own file line, goal line and tag, listed
# before the original in the path, both with the piece's title.
#
# Every file is public domain or dedicated CC0. The hands, the range and the difficulty shown on a
# tile are read from the file when the screen opens; this file does not repeat them. The files are
# made by scripts/make-melodies.py, in three kinds, which the source field says:
#   "Own transcription ...": we wrote the notes of a public-domain tune (CC0-1.0); the source field
#       names the printed score or public-domain MIDI file it was checked against, where there is one.
#   "Derived from ...": the notes are a public-domain MIDI file's (Mutopia, HymnWiki), cut, split into
#       hands or transposed as the field says; the licence is the one the piece's page gives.
#   "Mutopia Project, piece N": the file as the project offers it, except fur-elise.mid, which stops
#       where the piece's first section ends (the same script, --cut at tick 13536).
#   An easy version: "Derived from ..." the file it simplifies (a piece already above); the notes of the
#       right hand are that file's, the left hand is written for it.
# Mutopia's pages said "Public Domain" on 2026-10-20, HymnWiki's page too.
